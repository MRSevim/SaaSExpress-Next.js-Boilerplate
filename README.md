# SaaSExpress

This is comprehensive **Next.js SaaS boilerplate** that includes auth, billing (coming soon), error tracking and more. It is ready to go, clone the repo and start adding to it.

## Features

- [ ] Authentication/Authorization
  - [x] Google and credentials authentication
  - [x] Password reset, account deletion and forgot password flows
  - [x] Middleware redirects
  - [ ] Admin role with special actions
- [ ] Subscription and Payments
  - [ ] Monthly and yearly plans
  - [ ] Automatic recurring billing
  - [ ] Cancellation flow
  - [ ] Invoice history
- [x] Error Tracking
  - [x] Error reporting
  - [x] Sourcemap uploads
  - [x] Replay on errors and sessions
- [ ] To do app
  - [ ] Basic to do app replaceable by your real app logic
- [ ] SEO features
  - [ ] Sitemap and robots.txt
  - [ ] Basic pagewise metadata
- [x] Dark Theme
  - [x] Theme toggler
  - [x] Theme responsive pages
- [ ] Admin dashboard
  - [ ] User management
  - [ ] Basic analytics for the SaaS
- [ ] User dashboard
  - [ ] Profile page
  - [ ] Basic notifications
- [ ] User facing pages
  - [x] Homepage with features, pricing and call to action sections
  - [x] Contact page
  - [x] Terms and Conditions and Privacy Policy pages
- [ ] Email System
  - [x] Auth related emails
  - [ ] Welcome emails
  - [ ] Invoice and billing emails
- [ ] Dynamic flows
  - [ ] User friendly error messages
  - [ ] Loading indicators
  - [ ] Not found and error pages
  - [ ] Mobile friendly layouts
- [ ] Software Tests to check critical flows
  - [ ] Unit tests
  - [ ] End to end tests
- [x] Repository maintenance
  - [x] Code formatting
  - [x] Linting
  - [x] Typescript all around for type safety
- [x] CI/CD
  - [x] Formatting, linting, type-checking and testing as continuous integration
  - [x] Automatic database schema update on relevant file changes
